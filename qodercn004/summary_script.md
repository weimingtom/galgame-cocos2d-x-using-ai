# 脚本引擎实现总结

## 概述

本部分实现了GalGame引擎的脚本解析和执行系统，使游戏能够读取并执行`sample_script.txt`中的指令。

## 完成功能

### 1. 脚本解析器 (ScriptParser)

创建了完整的脚本解析系统，支持以下命令：

- **背景切换**: `背景: bg_name` - 切换游戏背景图片
- **角色进入**: `角色进入: position, "sprite_path"` - 在指定位置显示角色立绘
- **对话显示**: `对话: speaker, "text"` - 显示角色对话
- **选择分支**: `选择: "option1", "option2", ...` - 显示多选项菜单
- **等待指令**: `等待` - 暂停脚本执行，等待用户输入
- **条件语句**: `如果选择X:` / `否则如果选择Y:` / `否则:` / `结束选择` - 处理选择结果

### 2. 回调机制

通过回调函数将脚本命令与游戏组件连接：

- `setBackgroundCallback` - 背景切换回调
- `setCharacterCallback` - 角色操作回调
- `setDialogCallback` - 对话显示回调
- `setChoiceCallback` - 选择菜单回调
- `setWaitCallback` - 等待动作回调

### 3. GameScene集成

更新了GameScene以集成脚本解析器：

- 初始化脚本解析器实例
- 设置所有回调函数
- 加载示例脚本文件
- 实现脚本执行控制逻辑
- 添加触摸事件处理（点击屏幕推进脚本）

## 图片生成工具

创建了`generate_images.py`脚本，特点包括：

- 使用PIL/Pillow库进行图像处理
- 自动生成渐变色背景
- 绘制简易动漫风格角色立绘
- 支持自定义颜色和尺寸参数
- 自动保存到Resources/images目录

## 使用方法

1. 运行游戏时，脚本会自动加载`sample_script.txt`
2. 点击屏幕或按任意键推进脚本执行
3. 遇到选择时会显示选项菜单供玩家选择
4. 根据选择跳转到不同的剧情分支
